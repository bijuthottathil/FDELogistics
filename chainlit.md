# Cold-Chain Incident Control Dashboard

Query fleet telemetry, corridor weather/congestion, and compliance SOPs in plain language. Log in with your dispatcher or admin credentials to begin.

- **Dispatcher login** — Dispatch Console only
- **Admin login** — Dispatch Console + type `audit` to view the agent's audit trail

See [`ARTICLE.md`](ARTICLE.md) and [`README.md`](README.md) for what this system does and why.
